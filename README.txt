DREAM HAUS DESIGNER — QUICK START

1. Extract the ZIP file.
2. Open the Dream_House_Designer folder in VS Code.
3. Open index.html in Chrome, or use VS Code Live Server.
4. Start from index.html and use the navigation menu.

FEATURES
- 33 separate HTML pages
- House design selection and customization
- Wall colour selector and house add-ons
- Furniture selection
- Budget calculator with contingency buffer
- Save design and save budget
- Saved designs, wishlist, dashboard, compare, report, checklist
- Feedback form and demo admin dashboard
- Responsive layout for mobile and laptop

IMPORTANT
This is a front-end demo designed to run immediately without installing a database.
It saves demo data using browser localStorage, so it persists in the same browser/device.
It is NOT a real online database and does not securely authenticate users.
For a true shared database, add a PHP + MySQL backend (for example using XAMPP).
All listed costs are sample estimates, not actual construction quotes.
The images are loaded from Unsplash URLs, so internet is needed for those photos.

SUBMISSION TIP
Run index.html first, then demonstrate:
1) House Designs -> Customize
2) Furniture -> Add items
3) Budget -> Calculate total -> Save budget
